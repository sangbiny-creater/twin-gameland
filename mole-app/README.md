# 두더지 게임 앱 (`mole-app/`)

두더지 게임 한 가지만 하는 **단독 앱**이에요. 다운힐 러너 앱(`downhill-app/`)과 같은 틀로 만들었고, 나중에 앱스토어·플레이스토어에 올릴 앱의 바탕이에요.
트윈 게임랜드 사이트(`index.html`, `hub/`, `mole/`)와는 따로 동작하고, 사이트 파일을 건드리지 않아요.

- 주소(임시): **https://sangbiny-creater.github.io/twin-gameland/mole-app/** (백오피스 `/twin-gameland/mole-admin/`)
- 나중에 따로 주소(예: `mole.brown-crab.com`)를 쓰려면: 새 저장소 `sangbiny-creater/mole` + 가비아 DNS 설정 뒤 `bash tools/publish_mole.sh` (다운힐과 같은 방식, 아직 안 함)
- 로컬: 저장소 맨 위 폴더에서 `python3 -m http.server 8080` → http://localhost:8080/mole-app/

## 게임 규칙 (사이트 두더지와 다른 점)

- **판(스테이지)이 없어요.** 한 판이 끝없이 이어지고, **하트 3개가 다 없어지면 끝**. 점수와 BEST(최고 점수)를 남겨요.
- 두더지를 놓치거나 함정 캐릭터(은유·은결 — 어른 모습·어린이 모습 넷 중 무작위, `assets/chars/*_kid*` 는 예전 사이트 v0.3 그림)를 누르면 하트 -1. 하트 두더지를 잡으면 하트 +1 (꽉 차 있으면 +300점).
- **시간이 갈수록 빨라져요** (`game.js` 의 `diff()` — 게임한 시간 기준, 절대 쉬워지지 않음):

| 게임한 시간 | 두더지가 머무는 시간 | 새 두더지 간격 | 한꺼번에 나오는 수 |
|---|---|---|---|
| 0초 | 2.1초 | 1.3초 | 1 |
| 1분 | 1.25초 | 0.85초 | 3 |
| 2분 | 0.86초 | 0.63초 | 4 |
| 4분 | 0.61초 | 0.47초 | 4 |

  빠른 두더지(8초부터)·2대 두더지(20초부터)·함정(은유·은결 둘 다)이 점점 많아져요.
  20초마다 레벨 +1 ("빨라져요! 레벨 N"), 배경 음악도 조금씩 빨라져요.

## 화면 흐름 (다운힐 앱과 같음)

1. **인트로** — 세로 인트로 그림만 (START 버튼 없음). 누르거나 2.5초 뒤 다음으로. 완전 처음이면 **언어 고르기**(한국어 / English).
2. **로그인** (처음 한 번) — 구글 · 이메일(가입하기·비밀번호 재설정 메일) · 게스트.
3. **약관 동의** → 4. **이름 만들기** (영어 15자 · 한글 7자, 한글 한 글자 = 2칸, 같은 이름은 하나만)
5. (캐릭터 고르기 없음 — 게임에 내 캐릭터가 나오지 않아서 뺐어요. 창 색은 늘 분홍)
6. **시작 창** — 로고 · 이름/BEST · "시작하기" · "랭킹보기", 오른쪽 위 설정. (무한 방식이라 "N판부터"는 없음)
7. **게임** — 맨 위 광고 자리, 그 아래 게임. 3·2·1 뒤 시작. 왼쪽 위 일시정지(계속하기·다시하기).
8. **결과** — "게임 끝" / 기록을 깨면 "최고 기록 달성!" + NEW BEST! · "광고 보고 이어하기"(한 판에 한 번, 하트 1개로 3·2·1 뒤 이어서) · "다시하기"(= 시작 창) · "자랑하기" · 오른쪽 위 X.
9. **자랑하기** — 공유 창 → 없으면 문자·링크 복사. 친구 링크 `?from=점수&by=이름` → 시작 창 "OOO님 점수 N점을 넘어 보세요!", 결과에 넘었는지.
10. **랭킹** — 주간/전체 + 점수(한 판 최고)/잡은 두더지(합) 탭. 내 줄을 누르면 자랑하기.

가로 화면은 지원하지 않아요 ("세로로 돌려 주세요"). PC에서는 가운데 세로 칸.

## 파일

| 파일 | 내용 |
|---|---|
| `index.html` · `app.css` · `app.js` | 앱 화면과 흐름 (`downhill-app/` 의 것을 복사해서 두더지에 맞게 고침) |
| `game.js` · `style.css` | `mole/game.js` 를 **복사**해서 무한 방식으로 고친 것. 원본 게임 그림·소리를 고치면 여기에도 옮겨야 해요 |
| `assets/` | 두더지 그림(`mole/assets` 에서 쓰는 것만) + `assets/app/`(인트로·임시 배경·임시 아이콘·공유 미리보기) |
| `lib/` | 공통 파일 복사본: 캐릭터 고르기 그림(`chars/`), 글꼴, 하트·왕관·팝업·랭킹 그림, `i18n.js`·`i18n_data.js`(영어 표 — 앱 글자를 바꾸면 여기에도 영어를 넣기), `firebase_config.js` |
| `manifest.json` | 앱 이름·아이콘, 세로 고정 |

앱으로 묶을 때 폴더 하나만 있으면 되도록 `../common/` 같은 바깥 파일은 쓰지 않아요.

## 저장

- 이 기기: `localStorage` 의 `mole_app_v1` (로그인·약관·이름·캐릭터·BEST·판 수·언어·소리). 사이트(`twin_gameland_v1`)·다운힐 앱(`downhill_app_v1`) 저장은 안 건드림.
- 서버: **두더지 전용 Firebase 프로젝트** (BROWN CRAB — 트윈 게임랜드·다운힐과 계정·이름·기록 완전 분리). 아직 안 만들어서 `lib/firebase_config.js` 가 비어 있고,
  그동안은 게스트만·이 기기 기록만 (구글·이메일 로그인 버튼 숨김, 랭킹 안 보임). 만드는 법은 `mole-android/README.md` 1번.
  규칙 `mole-admin/server/firestore.rules`. 프로젝트가 바뀌면 기기에 남은 예전 로그인은 지우고 로그인부터 다시 (`Save.data.pid`).
  - `users/{uid}.mo` = { name, best, plays, agreedAt, agreeVer, createdAt, lastAt }
  - `records` (game `mole-app`) — score = 점수, coins = 잡은 두더지, zone = 레벨, combo, sec
  - `names/{이름}` (app `mole`) — 같은 이름은 하나만
  - `config/mole` — 공지·점검 · `config/mole_terms` — 앱 안 약관 글 (백오피스에서 씀)

## 백오피스

`mole-admin/` (앱 폴더 밖) — 다운힐 백오피스 복사본. 두더지 프로젝트의 관리자 구글 계정(`admins/{이메일}`)으로 로그인.
입구: https://brown-crab.com/admin/ (다운힐 · 두더지 · 트윈 게임랜드 버튼). 대시보드 · 사용자 · 기록·순위 · 이름 · 약관 · 운영(공지·점검).

## 아직 임시인 것 / 정할 것

- 앱 이름 "두더지 게임 / Whack-A-Mole" (임시 — 사이트 로고 그대로), 아이콘·배경 (임시 — GPT 요청 글 `making_GPT/두더지앱/`).
- 주소: 지금은 트윈 게임랜드 저장소 안. 따로 주소를 쓰면 `app.js` WEB · `index.html` og: 주소 · `tools/publish_mole.sh` DOMAIN 을 바꾸기.
- 광고: 웹에서는 가짜(3초). **안드로이드 앱(`mole-android/`)에서는 AdMob 진짜 광고** — 맨 위 배너 + 광고 보고 이어하기(보상형). 지금은 구글 테스트 광고 ID (`lib/ads_config.js`).
- 앱 전용 코드: `lib/native.js` (광고·앱 안 구글 로그인·뒤로 가기 버튼). 웹에서는 아무것도 안 함.
- 난이도 빠르기(`diff()` 숫자)는 실제 폰으로 해 보고 맞추기.
