# 사천성 스테이지 표 (100판)

`shisen/levels.js`에서 자동으로 계산한 값이에요. 판 크기는 가로 × 세로(폰 세로 화면 기준)이고, 1층 판은 8×12를 넘지 않아요.

## 난이도 기준
- 레퍼런스: Onet 계열 앱 **Onet Puzzle: Tile Connect (NoGame Studio, 60판)**. 10-10이 그 게임 마지막 판 수준이 되도록 맞췄어요(큰 판 약 144개 타일을 5분 안에, 그림 36~40종).
- Onet의 중력(짝을 없애면 타일이 미끄러짐)과 자동 완성·목숨 같은 아이템은 넣지 않았어요. 아이템은 우리 것(힌트·섞기·시간 추가·폭탄)만 써요.
- 그림 종류: 8종 → 36종. 기본 그림에 다른 게임(메모리·두더지·베이커리·헬리콥터·다운힐·계단)의 아이콘 그림 34종을 더해, 판마다 무작위로 뽑아요. 제한 시간: 타일당 4.5초(1-1) → 2.6초(7-10), 8-1부터는 판마다 조금씩 짧아져 10-10은 **5:00**(타일당 약 2.1초). 어떤 판도 5:45를 넘지 않아요.
- 별 3개 = 시간 절반 이상 남기기, 별 2개 = 4분의 1 이상.

## 2층 규칙
- 3월드부터 1층 판 가운데에 작은 2층 판이 얹혀요(3-1은 2×2 = 4개 → 10-10은 6×8 = 48개). 2층 타일은 하늘색 바탕, 1층은 크림색 바탕이에요.
- **2층끼리**: 2층에서 이어요(1층 타일 위로 지나갈 수 있음). **1층끼리**: 보통 사천성처럼 이어요.
- **2층 ↔ 1층**: 위에서 봤을 때 바로 옆이거나, 둘 다 각자 층에서 판 밖으로 곧장 나갈 수 있으면 이어요.
- 모든 판은 미리 끝까지 풀어 보고 그 순서대로 그림을 놓아요. 막히면 끝까지 풀리게 자동으로 섞어요.
