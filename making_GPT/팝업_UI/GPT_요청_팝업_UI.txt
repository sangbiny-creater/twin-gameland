[트윈 게임랜드 — 팝업 UI 세트 8장 (P01~P08)]
어린이 게임의 모든 팝업 창에 같이 쓰는 그림 세트야. 첨부 ①②③이 지금 쓰는 그림인데 그림체·색(하늘색 테두리·크림색 안쪽·분홍 리본·반짝이는 젤리 버튼)은 아주 마음에 들어.
문제는 창 크기에 따라 그림을 늘려 쓰는데, 옆면의 점·반짝이와 아래 모서리 별이 늘어나거나 버튼에 가려지는 거야. 그래서 "늘려 써도 모양이 그대로인" 세트로 다시 그려 줘.
한 답변에 1장씩, 다 그리면 "다음: P02"처럼 한 줄만 쓰고 멈춰. 내가 "계속"이라고 하면 다음 장. 질문하지 마.

[첨부 그림]
① 참고_지금_창틀 ② 참고_지금_리본 ③ 참고_지금_버튼: 지금 그림 (그림체·색 기준).
④ 참고_지금_배치: 게임에 들어간 지금 모습 — 창 폭은 모두 같고, 버튼은 "광고 줄 / 큰 버튼 한 줄 / 같은 폭 두 버튼" 세 줄 규칙으로 놓여.

[공통 규칙]
1. 이미지 생성 기능으로만 그려. 코드·도형으로 그리지 마. 파일 저장·zip·파일 이름 붙이기 하지 마.
2. 배경은 아무것도 없는 순수한 초록색(#00FF00) 한 색. 그림 하나만 가운데, 잘리지 않게, 정면에서 본 평평한 모습(기울이지 마).
3. 글자·숫자·아이콘 넣지 마 (글자는 내가 코드로 넣어).

P01 창 틀 (세로로 조금 긴 직사각형, 폭:높이 = 3:4)
  - 하늘색 젤리 테두리 + 안쪽은 무늬 없는 크림색 한 색 (지금 ①과 같은 색).
  - 테두리 두께는 어디나 같게. 네 모서리는 둥글게.
  - 장식은 네 모서리(위 왼쪽 하트, 위 오른쪽 하트, 아래 양쪽 별 + 작은 분홍 별)와 위 가운데 구름 장식에만.
  - 모서리 장식은 테두리 바깥쪽에 반쯤 걸치게 — 안쪽 크림색 칸을 덮지 않게.
  - 옆면·윗면·아랫면의 가운데 부분(모서리 장식 사이)은 점·별·반짝이·무늬 없는 민무늬 테두리만 (그래야 늘려도 모양이 같아).
P02 제목 리본 (가로로 긴 리본, 폭:높이 = 4:1)
  - ②와 같은 분홍 리본, 양쪽 끝에 노란 별과 하트 장식.
  - 가운데 글자 칸은 리본 폭의 65% 이상, 무늬 없는 분홍 한 색, 위아래로 반듯하게(구부러지지 않게).
P03 큰 버튼 분홍 / P04 버튼 파랑 / P05 버튼 회색(못 누를 때) — 세 장 모두 같은 크기·같은 모양
  - 가로로 긴 알약 모양 젤리 버튼 (폭:높이 = 4:1), 양쪽 끝은 반원.
  - 반짝이 하이라이트는 양쪽 끝 둥근 부분 근처에만, 가운데는 같은 색 민무늬 (옆으로 늘려 써).
  - 아래쪽에 살짝 진한 색 두께(눌리는 버튼 느낌), 테두리는 진한 갈색 얇은 선 — ③과 같은 그림체.
P06 광고 버튼 보라 / P07 광고 버튼 초록 — 두 장 같은 크기·같은 모양
  - P03과 같은 알약 모양, 왼쪽 끝 안에 아이콘이 들어갈 흰 동그라미 하나 (버튼 높이의 75%).
  - 가운데·오른쪽은 민무늬 (글자가 들어감), 반짝이는 오른쪽 끝에만.
P08 작은 닫기 버튼
  - 동그란 분홍 젤리 버튼 안에 흰색 X 하나 (이건 글자 대신 X 모양만), 크기는 버튼 높이와 같은 지름.
