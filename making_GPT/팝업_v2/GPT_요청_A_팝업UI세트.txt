=== 붙여 넣기 ===
[트윈 게임랜드 — 게임 팝업 UI 세트 12장 (A01~A12)]
어린이 미니게임 모음의 "게임 시작 / 게임 끝 / 일시정지" 팝업에 쓰는 UI 부품 그림이야.
첨부 ①②는 네가 전에 그려 준 팝업 시안인데, 그림체와 색(하늘색 젤리 테두리, 크림색 안쪽, 분홍 리본, 통통하고 반짝이는 젤리 버튼, 노란 별·하트 장식)이 아주 마음에 들어.
이번에는 그 시안을 "부품"으로 나눠서 따로따로 그려 줘. 내가 코드로 조립하고 글자는 내가 넣어.
첨부 ③ 배치 안내도는 부품이 어디에 놓이는지 보여 주는 그림이야 (그대로 그리는 게 아니라 참고만).
한 답변에 1장씩 순서대로 그리고, 다 그리면 "다음: A02"처럼 한 줄만 쓰고 멈춰. 내가 "계속"이라고 하면 다음 장. 질문하거나 확인을 기다리지 마.

[모든 그림 공통 규칙]
1. 이미지 생성 기능으로만 그려. 파이썬·코드·도형으로 그리지 마. 파일 저장·zip·파일 이름 붙이기도 하지 마.
2. 배경은 완전히 평평한 초록색(#00FF00) 한 가지 색. 그림 안에는 밝은 초록을 쓰지 마. 그림자·빛 번짐은 그림 안쪽에만.
3. 글자·숫자를 넣지 마 (A11만 예외). 버튼·리본·칸은 모두 비워 둬.
4. 정면에서 본 평평한 모습. 기울이거나 원근을 주지 마.
5. 한 장에 여러 개를 그릴 때는 서로 넉넉히 떨어뜨리고(겹치거나 붙지 않게), 같은 종류는 모두 똑같은 크기·똑같은 모양으로 반듯하게 줄 세워 (색만 다르게).
6. 그림체: 첨부 ①② 시안과 같은 시리즈 — 부드러운 수채화풍 치비 게임 UI, 진한 갈색 얇은 외곽선, 통통한 입체감, 위쪽 반짝 하이라이트.

[그릴 그림 12장]
A01 창 틀 — 세로 그림 1장
  세로로 조금 긴 둥근 창 하나 (폭:높이 = 3:4). 두꺼운 하늘색 젤리 테두리 + 안쪽은 무늬 없는 크림색 한 색.
  테두리 두께는 어디나 같게. 장식은 네 모서리(위 양쪽 분홍 하트, 아래 양쪽 노란 별+작은 분홍 별)와 위 가운데 작은 구름 볼록에만.
  모서리 장식은 테두리 바깥쪽에 반쯤 걸치게 — 안쪽 크림색 칸을 덮지 않게.
  옆면·윗면·아랫면의 가운데 부분은 점·별·반짝이 없는 민무늬 테두리만 (늘려 써도 모양이 같게).
A02 그림 칸 배경 — 가로 그림 1장 (폭:높이 = 16:9)
  팝업 위쪽에 들어가는 둥근 모서리 사각형 그림. 맑은 하늘, 구름, 멀리 파란 지붕 성, 대관람차, 회전목마가 있는 밝은 놀이공원 풍경.
  가운데 아래쪽은 캐릭터가 서 있을 수 있게 비워 두고(풀밭·돌길 정도만), 사람·캐릭터는 그리지 마. 테두리 없이 그림만, 모서리는 둥글게.
A03 제목 리본 — 가로 그림 1장 (폭:높이 = 4:1)
  첨부 시안 맨 위와 같은 분홍 리본. 양쪽 끝은 접힌 꼬리 + 노란 별과 하트 장식.
  가운데 글자 칸은 리본 폭의 65% 이상, 무늬 없는 분홍 한 색, 위아래로 반듯하게(구부러지지 않게).
A04 버튼 바탕 5개 — 세로 그림 1장, 위에서 아래로 줄 세워
  ① 분홍 ② 파랑 ③ 민트(청록빛, 배경 초록과 확실히 다른 색) ④ 보라 ⑤ 연한 회색(못 누를 때).
  모두 가로로 긴 알약 모양(폭:높이 = 4:1), 양쪽 끝은 반원, 똑같은 크기. 첨부 시안의 버튼처럼 통통한 젤리, 아래쪽에 살짝 진한 두께.
  반짝이 하이라이트는 양쪽 끝 둥근 부분 근처에만, 가운데는 같은 색 민무늬 (옆으로 늘려 써).
A05 광고 버튼 2개 — 가로 그림 1장, 위아래로 줄 세워
  ① 노랑~주황 ② 초록~청록 (배경 #00FF00와 확실히 다른, 진하고 푸른빛 도는 초록). 둘 다 같은 크기의 가로로 긴 알약 버튼(폭:높이 = 3.5:1).
  오른쪽 끝에 빨간 둥근 네모 "광고 재생" 배지(흰 재생 ▶ 모양, 작은 반짝 선 몇 개) — 첨부 ② 시안의 "광고 보고 2배 받기" 배지 느낌. 배지는 버튼 높이 안에 들어오게.
  배지 왼쪽은 민무늬 (글자가 들어감).
A06 작은 동그라미 버튼 2개 — 가로 그림 1장, 나란히
  ① 닫기: 분홍 젤리 동그라미 안에 흰색 X 모양 ② 일시정지: 하늘색 젤리 동그라미 안에 흰색 세로 막대 두 개(II). 같은 크기.
A07 아이템 칸 2개 + 수량 배지 1개 — 가로 그림 1장, 나란히
  ① 기본 칸: 크림색 둥근 정사각형, 연한 베이지 테두리 ② 고른 칸: 같은 모양, 진한 분홍 테두리 + 오른쪽 위에 분홍 동그라미 안 흰 체크(✓)
  ③ 작은 갈색 동그라미 배지 (안은 비워 둠, 숫자가 들어감). 칸 ①②는 같은 크기, 칸 안은 비워 둬 (아이템 그림은 내가 넣어).
A08 아이템 아이콘 6개 — 정사각형 그림 1장, 2줄 x 3칸
  1줄: ① 보호막(금빛 테두리 하늘색 방패 + 노란 별) ② 슬로우(귀여운 달팽이) ③ 시간 추가(빨간 탁상시계 + 작은 반짝, 숫자 없이)
  2줄: ④ 힌트(노란 전구) ⑤ 폭탄(검은 동그란 폭탄 + 불꽃 심지) ⑥ 모두 보기(커다란 반짝이는 눈 하나)
  모두 같은 크기·같은 그림체(통통한 젤리 입체감), 아이콘끼리 크기 차이 없게.
A09 버튼 위 흰 아이콘 9개 — 정사각형 그림 1장, 3줄 x 3칸
  모두 흰색 + 진한 갈색 얇은 외곽선, 같은 굵기: ① 재생 ▶ ② 다시(동그란 화살표) ③ 집 ④ 지도 핀 ⑤ 다음(▶▶) ⑥ 네모 4칸 격자(게임 선택) ⑦ 일시정지 막대 두 개 ⑧ 하트+동그란 화살표(이어하기) ⑨ 코인 두 개(2배)
A10 별 2개 — 가로 그림 1장, 나란히
  ① 반짝이는 큰 노란 별 (결과 별) ② 같은 모양·크기의 빈 별 (연한 회색, 안쪽 비어 보이게).
A11 제목 글자 그림 3개 — 가로 그림 1장, 위에서 아래로 (이 장만 글자를 그려)
  ① "CLEAR!" — 노랑·주황 통통한 글자, 흰 테두리 + 진한 갈색 외곽선, 반짝이 조금
  ② "FAIL" — 같은 글씨체, 연한 파랑·보라 글자 (슬픈 느낌, 작은 눈물방울 하나)
  ③ "NEW BEST!" — 같은 글씨체, 분홍·노랑 글자 + 작은 왕관 하나
  철자를 정확히: CLEAR! / FAIL / NEW BEST! (다른 글자 넣지 마). 세 개 모두 같은 글자 높이.
A12 결과 줄 아이콘 6개 — 정사각형 그림 1장, 2줄 x 3칸
  ① 빨간 깃발(거리) ② 금빛 코인 ③ 노란 별 ④ 금빛 왕관(최고 기록) ⑤ 파란 스톱워치(시간) ⑥ 파란 다이아. 모두 같은 크기.
