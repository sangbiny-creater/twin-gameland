[버거 러시 (Burger Rush) — 게임 기획 (이 글은 GPT에 보내지 않아요)]
2026-11-08 처음 씀. 그림을 받기 전 계획이에요. 숫자는 만들면서 직접 해 보고 조금씩 바꿀 수 있어요.
게임 id(코드 이름): burger

[어떤 게임]
햄버거 가게 타이쿤. 은유·은결이 주인인 작은 버거 가게에 손님이 와서 햄버거와 사이드 메뉴를 주문해요.
손님이 기다리다 화나서 떠나기 전에, 주문대로 버거를 쌓고 사이드를 담아 내줘요.
실제 있는 버거 가게 게임을 따라 하지 않아요: 가게 이름·로고·그릇 색은 모두 우리 게임만의 모양 (브랜드 비슷한 빨강·노랑 조합 피함).

[화면 방향 — 가로 전용]
- 게임 판은 가로로만 해요.
- 폰을 세로로 들면: 게임이 완전히 멈추고(손님 시간·패티 굽기 모두 정지, 움직이는 그림 없음) "폰을 가로로 돌려 주세요" 안내 한 장만 보여요.
- 다시 가로로 돌리면 일시정지 창이 먼저 나와요. '계속하기'를 눌러야 다시 시작 (갑자기 시작되어 손님을 놓치지 않게).
- 인트로·스테이지 지도는 다른 게임처럼 세로·가로 둘 다 보여요 (게임 판에 들어갈 때만 가로가 필요). ← 사용자 확인 필요
- 화면 틀: 게임 판은 16:9(960x540 기준)로 만들고, 더 긴 폰(19.5:9)은 양옆을, 태블릿(4:3)은 위아래를 배경으로 채워요.

[가로 화면 배치 (위 → 아래)]
 0~10%   위 줄: 일시정지(왼쪽 위) · 스테이지 이름 · 남은 손님 수 · 하트 3개 · 코인
 10~48%  손님 자리: 카운터 너머로 손님이 2~4명 서 있어요. 머리 위에 주문 말풍선, 옆에 기다림 막대.
 48~56%  카운터 (손님 허리 아래를 가림)
 56~86%  주방: 왼쪽 굽는 판(2~4칸) · 가운데 쟁반 2개 · 오른쪽 사이드 기계(음료·튀김·아이스크림) · 쓰레기통
         고른 캐릭터(은유 또는 은결) 상반신이 왼쪽 끝에서 반응해요.
 86~100% 재료 칸 한 줄: 생패티 · 빵 · 양상추 · 토마토 · 양파 · 치즈 · 베이컨 (그 판에서 쓰는 것만)
         사이드 칸: 콜라 · 사이다 · 감자튀김 · 치킨너겟 · 아이스크림 (그 판에서 쓰는 것만, 오른쪽 기계 앞)

[조작 — 모두 "누르기"만으로 할 수 있게 (끌어서 옮겨도 돼요)]
1. 쟁반 고르기: 쟁반이 2개면 누른 쟁반이 '지금 쟁반'(분홍 빛 테두리). 1개일 때는 고를 필요 없음.
2. 생패티 칸 누르기 → 비어 있는 굽는 칸에 패티가 올라가요 (빈 칸이 없으면 칸이 흔들림).
3. 굽는 판의 패티 아래 진행 막대: 회색으로 차오름(굽는 중) → 초록(다 익음, 쓸 수 있음) → 주황·빨강(타기 직전) → 검정(탐).
   다 익은 패티 누르기 → 지금 쟁반 맨 위로. 탄 패티 누르기 → 쓰레기통으로.
   쉬운 판에서는 패티가 아예 타지 않아요 (막대가 초록에서 멈춤).
4. 재료 칸 누르기 → 지금 쟁반 맨 위에 그 재료가 쌓여요. 쌓인 모양이 그대로 보여요.
5. 빵 칸: 쟁반이 비어 있으면 아래 빵, 재료가 올라가 있으면 위 빵(= 버거 완성, 뚜껑 덮기).
6. 사이드 칸 누르기 → 컵 채우기·튀기기 짧은 연출(0.5~1초) 뒤 쟁반 옆자리에 놓여요. 사이드는 타거나 실패하지 않아요.
7. 내주기: 버거(위 빵까지)와 사이드가 어떤 손님의 주문과 딱 맞으면, 그 손님에게 저절로 가요 (같은 주문이 둘이면 오래 기다린 손님 먼저).
   위 빵을 덮었는데 맞는 손님이 없으면 쟁반이 흔들리고 "주문을 다시 봐요" 표시.
8. 쓰레기통 누르기 → 지금 쟁반을 비워요 (재료만 버려지고 벌은 없음).
9. 손님의 주문 말풍선 누르기 → 큰 창에 그 버거의 재료가 위에서 아래 순서로 그림+이름으로 보여요 (게임은 그동안 잠깐 멈춤, 한 번 더 누르면 닫힘).

[주문을 맞추는 기준] ← 사용자 확인 필요
- 추천: 재료의 "종류와 개수"만 맞으면 OK, 쌓는 순서는 상관없음 (아래 빵 처음, 위 빵 마지막만 정해짐).
- 다른 안: 어려움 6월드부터는 순서까지 똑같이.
- 말풍선 속 버거 그림은 정해진 보기 좋은 순서로 그려요 (아래부터: 빵 → 패티 → 치즈 → 베이컨 → 양파 → 토마토 → 양상추 → 빵).

[손님]
- 한 판에 정해진 수의 손님이 차례로 와요. 카운터에 동시에 서는 손님 수는 판마다 정해져 있어요 (1~4명).
- 손님마다 기다림 막대: 초록(웃음) → 노랑(조금 지루, 50% 남음) → 빨강(화남, 25% 남음) → 0이 되면 화내며 떠나요.
- 버거를 받으면 기쁨 표정 + 코인. 막대가 초록일 때 받으면 팁 동전을 더 줘요.
- 손님은 동물 마을 주민 8명 (곰·토끼·고양이·강아지·판다·펭귄·여우·너구리). ← 사용자 확인 필요 (사람 손님으로 바꿀 수도)

[하트·별·실패]
- 하트 3개 (공통 하트 그림). 손님이 화나서 떠나면 하트 1개가 빠져요.
- 하트가 0이 되면 실패 (결과 창: 다시하기·지도로).
- 패티를 태우거나 잘못 만들어도 하트는 안 빠져요 (시간만 손해).
- 판의 손님을 모두 받으면(또는 떠나고 하트가 남으면) 클리어.
- 별: 하트로 정해요. 하트 3개 그대로 ★3 / 1개 잃음 ★2 / 2개 잃음 ★1.
- 코인: 손님 1명마다 기본 코인 + 팁, 클리어 보너스. 정확한 값은 common/profile.js COIN_RULES 에 넣을 때 다른 게임과 맞춰요.
- 처음 1판에는 손가락 안내(생패티 → 굽기 → 쟁반 → 빵)로 한 번 보여 줘요.

[재료와 사이드가 나오는 순서]
재료(버거 안): 빵·패티·치즈 → 양상추 → 토마토 → 양파 → 베이컨 → (패티 2장 버거)
사이드: 콜라·감자튀김 → 사이다 → 치킨너겟 → 아이스크림(10월드만)
"버거 속 재료 수" = 위·아래 빵을 뺀 나머지 (패티 포함).

[스테이지] 쉬움·어려움 각각 10월드 × 10판 = 200판. 지도는 기존 게임처럼 징검다리 (월드 배경 10장).
어려움 N월드는 쉬움 N월드를 다 깨면 열려요 (사천성과 같음).
사천성·메모리·두더지·선물가게와 같은 난이도 사다리: 쉬움1 < 쉬움2 < 어려움1 < 쉬움3 < 어려움2 < … < 쉬움10 < 어려움9 < 어려움10.
판 안에서는 1판 → 10판으로 갈수록 손님 수가 늘고, 다음 월드 숫자로 조금씩 다가가요. 어떤 값도 앞 판보다 쉬워지지 않아요.

[판이 쉬워지지 않게 확인하는 방법 (만들 때)]
- 판 200개를 표(levels.js)로 만들고, 사다리 순서대로 늘어놓아 아래 값이 하나라도 거꾸로 가면 오류로 멈추는 검사 도구를 같이 만들어요 (tools/burger_levels.mjs).
  재료 가지 수↑ · 버거 속 재료 수↑ · 사이드 가짓수↑ · 굽기 시간↑ · 타기 시간↓ · 대기 시간↓ · 손님 수↑ · 동시 손님↑
- 아이스크림은 사용자가 정한 대로 쉬움·어려움 10월드에만 나와요 (어려움 9월드에는 없지만 다른 값이 쉬움 10월드보다 어려워요).
- 대기 시간은 컴퓨터가 "가장 빠르게 만들면 몇 초"를 계산해서, 그 시간의 2배 이상은 꼭 남게 해요 (억지로 어려운 판이 없게).

[도움 아이템] 아이템샵을 새로 바꿀 때 같이 정해요. (예: 손님 시간 멈춤, 패티 자동 굽기) 지금 공통 아이템은 쓰지 않아요.
