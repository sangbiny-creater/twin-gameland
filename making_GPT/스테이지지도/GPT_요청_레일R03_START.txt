[트윈 게임랜드 — 스테이지 지도 START 문 1장 (ST01)]
스테이지 지도 왼쪽 아래에 놓을 START 아치 문이야. 첨부 ①처럼 분홍 아치에 "START!" 글자, 금색 기둥, 아래로 분홍 롤러코스터 레일이 오른쪽으로 나가는 모습. 질문하지 마.

[규칙]
1. 이미지 생성 기능으로만 그려. 코드·도형으로 그리지 마. 파일 저장·zip·파일 이름 붙이기 하지 마.
2. 배경은 순수한 초록색(#00FF00) 한 색. 문 하나만 가운데, 잘리지 않게. 정사각형 그림.
3. 기본 START 문만: 분홍 아치 + 흰 글자 "START!" + 위에 노란 별 하나 + 양쪽 금색 기둥 + 아래 작은 돌바닥. 판다·캐릭터·사람·큰 꽃 장식 없음.
4. 문 안쪽에서 분홍 롤러코스터 레일(첨부 ② 레일과 같은 색·굵기·침목)이 시작해서 문 오른쪽 아래로 짧게 나가 (그림 오른쪽 가장자리에서 끝).
5. 그림체는 첨부 ①과 같게.

=== 대화 ②에 붙여 넣기 ===
[첨부] 안내_레일R03_고칠곳.png, 참고_레일R02.png

[트윈 게임랜드 — 스테이지 지도 롤러코스터 레일 1장 (R03)]
첨부 ②의 레일을 고쳐서 다시 그려 줘. 레일과 노란 기둥만, 나머지는 순수한 초록색(#00FF00). 질문하지 마.

[첨부 그림]
첨부파일 하나는 지금의 화면.(색·굵기·기둥·그림체는 이대로)
다른 하나는 지금 화면에서 고칠 곳을 내가 빨간 선으로 표시했어. 빨간 선 = 레일을 이렇게 바꿔 달리는 길. 
안내_레일R03_고칠곳: 지금 화면에 고칠 곳을 표시한 그림. 빨간 동그라미 = 판이 놓일 새 자리, 초록 선 = 레일을 이렇게 바꿔 달라는 길.
② 참고_레일R02: 지금 레일 (색·굵기·기둥·그림체는 이대로).

[규칙]
1. 이미지 생성 기능으로만 그려. 코드·도형으로 그리지 마. 파일 저장·zip·파일 이름 붙이기 하지 마.
2. 크기는 꼭 세로 1024x1536. 레일 색·굵기·침목·노란 기둥은 ②와 똑같이.
3. 시작: 그림 왼쪽 아래(왼쪽 가장자리, 아래에서 1/8쯤 높이)에서 레일이 들어와. ①의 아래 초록 선처럼 오른쪽으로 가서 1번 동그라미 아래를 지나. 출발 승강장은 그리지 마 (START 문은 따로 얹어).
4. 1번 → 2번(오른쪽 아래 동그라미) → 그 뒤는 ②의 레일 길 그대로 올라가.
5. 9번 → 10번: ①의 위쪽 초록 선처럼 9번 오른쪽에서 부드럽게 아래로 둥글게 내려갔다가 10번 동그라미 아래로 올라가 끝나.
6. 끝: 레일은 10번 동그라미 아래에서 끝나. 맨 위 별 승강장·깃발은 그리지 마. 레일이 그림 위 가장자리 밖으로 나가지 않게.
7. 빨간 동그라미 자리에서 레일은 동그라미 아래쪽(앞쪽)을 지나가 (가운데를 덮지 않게).
8. 레일·기둥 말고는 전부 순수한 초록색(#00FF00). 글자·숫자·동그라미·선·섬·캐릭터 없음.
