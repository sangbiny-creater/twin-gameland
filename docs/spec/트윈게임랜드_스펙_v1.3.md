| **열쇠 (새로, 코드 `unlock_ticket`)** | 처음 1개(캐릭터마다 한 번), 출석 10일째 1개 | 잠긴 게임 1개 영구 열기 | 폰 안 저장 |

### 다이아로 게임 열기 가격 (v1.2 그대로 🟡)
다이아로 연 횟수만 셈(열쇠로 연 건 안 셈): 1번째 60 · 2번째 80 · 3번째 100 · 4번째 120 · 5번째 140 · 6번째 160 · 7번째 180.
- 일반적으로 다이아로 6개 열면 합계 **660개**.
- ⚠️ 무료로 버는 속도(출석 하루 1개 + 10판마다 1개)로는 아주 오래 걸림 → ❓ "모든 게임 열기" 한 번 구매 상품, 게임 클리어 보상 다이아 등 검토 필요.

### 출석 (v1.2 그대로 🟡)
- 누적(연속 아님), 하루 한 번, 날짜 경계 = 한국 시간 0시(웹은 폰 시계 기준).
- 매일 다이아 1개, 10일째 열쇠 1개, 30일째(❓ 프로필 프레임 자리), 50일째 다이아 20개, 100일째(❓ 특별 코스튬 자리).
- 웹 v0.3: 첫 화면에 처음 들어올 때 하루 한 번 출석 창이 뜸.

## 6. 잠금·체험 화면 흐름 (웹 v0.3)

1. 첫 화면 놀이공원: 잠긴 놀이기구에 **자물쇠 표시**.
2. 잠긴 놀이기구를 누르면 **"게임 열기" 창**: [열쇠로 열기] [다이아 N개로 열기] [체험해 보기].
3. 스테이지 게임 체험: 지도에서 1-1, 1-2만 들어갈 수 있고, 1-3부터 누르면 "게임 열기" 창.
4. 끝없는 게임 체험: 화면 위에 **"체험 30초"** 표시가 줄어들고, 끝나면 "체험이 끝났어요" + "게임 열기" 창.
5. 다이아가 모자라면 → 다이아 상점(가짜 결제).

## 8. 앱 단계에서 더 정할 것 (v1.2에 빠졌던 것)

- 코스튬 목록·가격 / 게임 안에서도 보일지 (캐릭터 동작 그림 14장 × 옷 수만큼 그림 필요)
- 다이아 상품 가격(원·달러), "모든 게임 열기" 상품 여부
- 판당 코인·EXP, 레벨 보상
- 보유 아이템 데이터(코스튬·프레임·배경·부스터)와 상점 구매 API
- 랭킹 부정행위 방지: 점수 상식선 검사 + Firebase App Check
- 메모리·사천성 랭킹 판은 같은 배치(고정 시드)로
- 구글 환불 시 다이아 회수 (voided purchases)
- 한국 필수: 청약철회 안내, 개인정보처리방침·이용약관, 게임 등급(IARC)
- 생년월일은 서버에 저장하지 않고 나이 구분만 (13세 이상 정책이면 생년월일 화면 자체를 뺄지 ❓)
- 영어판 그림(로고·카드·인트로에 한글 글자)
- Firebase 요금제(Blaze)·서버 지역(서울)·비용 알림
- 손님 = Firebase 익명 로그인 → 구글 계정 연결
- 저장소 비공개 전환
