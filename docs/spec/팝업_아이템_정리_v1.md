## 1. 게임 종류

| 종류 | 게임 |
|---|---|
| 무제한형 | 다운힐 런너(downhill) · 달콤 베이커리(bakery) · 무한계단(stairs) · 하늘타기(helicopter) · 멍멍이 간식 타임(dogsnack) |

## 2. 아이템 (아이템샵에서 파는 것 = 이것만)

게임 안에서 줍는 아이템(자석·코인 2배·날개 등)은 **게임 중에만** 나오고, 아이템샵에서는 안 팔아요.

| 아이템 | 하는 일 | 쓰는 게임 | 지금 이름(바뀜) |
|---|---|---|---|
| **하트** | 하트 3칸·2개 대신 **4칸·3개**로 시작. 게임 중 하트를 먹어 4칸까지 채울 수 있음. 가장 비쌈 | 무제한형 5개 + 두더지 | 추가 하트 · 추가 목숨 |
| **보호막** | 처음 한 번 안 다침 (지금과 같음) | 무제한형 5개 | 1회 보호 |
| **슬로우** | 천천히 시작 (지금과 같음, 없는 게임은 새로) | 무제한형 5개 | 천천히 시작 (다운힐·하늘타기는 새로) |
| **힌트** | 짝 하나 알려 줌 | 사천성 · 메모리 | 힌트 |
| **시간 추가** | 제한 시간 +10초 | 사천성 · 메모리 | 시간 추가 |
| **폭탄** | 짝 하나를 바로 이어 줌 | 사천성 · 메모리 | 폭탄 |
| **모두 보기** | 카드를 모두 보여 줌 | 메모리 | (메모리 아이템) |

- 무제한형 시작 팝업: 가진 아이템을 **눌러 체크 / 체크 안 함** 두 가지만 (수량은 못 고름). 체크한 것을 1개씩 쓰고 시작.
- ❓ **시계(시작 시간 +10초)**: 무한계단·하늘타기·멍멍이 설명에 있었지만 시작 팝업은 "아이템 3개(하트·보호막·슬로우)"라고 해서, 무제한형에서는 빼는 것으로 이해했어요. 남길지 확인 필요.
- 이미 사 둔 옛 아이템(자석·코인 2배·날개·대시·섞기·자동 찾기·콤보)은 저장 데이터에 그대로 두고 화면에만 안 보이게 (저장 데이터 깨지 않기).

### 아이템샵 '게임 부스트' 칸 바꾸기
- 게임별로 나누지 않고 **7개를 한 화면에** (하트·보호막·슬로우·힌트·시간 추가·폭탄·모두 보기).
- 카드: **아이콘 · 이름 · 가격**만 (설명 지움), 보유 수량은 카드 **오른쪽 위**.
- 누르면 구매 창 → 어떤 게임에 쓰이는지 설명.
- ❓ 수량을 게임마다 따로 셀지(지금 방식) / 모든 게임 같이 쓸지 → 같이 쓰는 쪽이 "한 화면" 판매와 맞아요.

## 3. 무제한형 팝업

### 시작 (인트로 START 뒤)
1. 제목 리본: 게임 이름 · 오른쪽 위 **X → 첫 화면**
2. 그림 칸: **지금 캐릭터**(은유/은결)가 게임 시작에 신난 모습
3. 아이템 3칸: 하트 · 보호막 · 슬로우 (좌우 넘김 버튼 없음). 가진 것은 눌러 체크, 안 가진 것은 누르면 구매 창
4. 버튼: [시작하기] [XX판부터 시작]
   - XX판 = 지금까지 깬 가장 높은 판의 **바로 전 판** (베이커리·멍멍이는 지금 "가장 높은 판"부터 → 한 판 전으로 바꿈)
   - 다운힐·무한계단·하늘타기에도 같은 기능을 새로 넣음 (판 개념이 없는 게임은 판을 나눠야 함 — 만들 때 판 길이 정해서 보여 드릴게요)

### 끝
1. 제목: 최고 기록 갱신이면 **NEW BEST!**, 아니면 게임 끝
2. 그림 칸: 갱신 = 지금 캐릭터 **기뻐함** / 못 함 = **슬퍼함**
3. 결과 칸: 점수(거리·높이) · 코인 · BEST
4. [광고 보고 2배 받기] [광고 보고 이어하기]
5. [다시하기] [메인으로]

---

## 4. 스테이지형 팝업

### 시작
1. 제목: 판 이름 · 오른쪽 위 **X → 팝업만 닫고 지도 보기**
2. 그림 칸: 사천성·메모리 = 지금 캐릭터 신난 모습 / **두더지 = 나오는 두더지 종류와 설명** (게임 속 두더지 그림 그대로 사용)
3. 아이템 칸: 사천성 3개 · 메모리 4개 · 두더지 1개(하트)
4. [시작하기] [메인으로]

### 끝
1. 제목: **CLEAR!** (+ 별 1~3개) / **FAIL**
2. 그림 칸: 별3 = 아주 기쁨 · 별2 = 기쁨 · 별1 = 살짝 미소 · 실패 = 슬픔
3. 결과 칸 (시간·코인·별 등)
4. [광고 보고 2배 받기] (한 줄 가득)
5. [다시하기] [다음 스테이지] — **실패면 [다음 스테이지] 자리에 [광고 보고 이어하기]**
6. [메인으로] [지도 보기]
- 광고로 이어하고도 실패하면 그 자리는 그대로 두고 **회색(못 누름)**.

---

## 5. 광고 버튼 (모든 팝업 같은 규칙)
- 광고 버튼은 TV·재생 표시 그림이 들어간 버튼 (첨부 시안처럼).
- 누르면 **광고 창 1초** → 진짜 광고를 본 것과 같은 흐름 (보상 받기 / 이어하기).
- 누른 버튼은 바로 **회색(못 누름)**.
- 이어하기: 광고가 끝나면 그 자리에서 이어서 — 단, **화면을 한 번 터치해야 다시 움직임** (바로 죽지 않게).

## 6. 일시정지
- 창: [계속하기](한 줄 가득) / [다시하기] [게임 선택] — 기능은 그대로, 그림만 새 세트로.
- 게임 화면 **왼쪽 위 일시정지 버튼**을 모든 게임 같은 그림·같은 크기·같은 자리로.

## 7. 팝업 공통 모양
- 모든 팝업: 같은 창 틀(A01) · 같은 폭 · 같은 리본(A03) · 같은 그림 칸 크기(A02) · 같은 버튼 크기(A04)
- 버튼 색 약속: 분홍 = 시작하기·다시하기·계속하기 / 파랑 = XX판부터·다음 스테이지 / 민트 = 메인으로·게임 선택 / 보라 = 지도 보기 / 회색 = 못 누름 / 노랑 = 광고 2배 / 초록 = 광고 이어하기
- 버튼·리본에는 글자를 그리지 않음 (영어판도 같은 그림). CLEAR!·FAIL·NEW BEST! 제목 글자만 그림.
