# 트윈 게임랜드

은유·은결 캐릭터로 여러 미니게임을 하는 모음집입니다. 캐릭터·코인·기록은 **이 기기(브라우저)에 저장**됩니다.

## 실행

```bash
cd /Users/choisangbin/Documents/minigame
python3 -m http.server 8080 --bind 0.0.0.0
```

- PC: http://localhost:8080
- 아이폰(같은 Wi‑Fi): http://<맥 IP>:8080 (맥 IP: `ipconfig getifaddr en0`)

## 흐름

1. **캐릭터 선택(첫 화면)** — 처음엔 2명(은유·은결)까지 무료로 만들 수 있어요. 3번째부터는 코인으로 자리를 사요 (300 → 600 → 900 …, 최대 8명).
2. **게임 고르기** — 캐릭터를 고르면 게임 목록이 나와요. 아이템샵은 '오픈 예정'.
3. **Sky Hook Runner** — 징검다리 지도에서 스테이지를 골라요. 12스테이지(1-1 ~ 4-3), 앞 판을 깨야 다음 판이 열려요. 남은 하트 = 별(최대 3개).
4. **Twin Helicopter** — 끝없이 날아가며 최고 거리를 갱신해요.
5. **기록** — 캐릭터별 코인, 게임별 최고 기록·도전 횟수, 최근 기록 30개. 이름 바꾸기 / 캐릭터 삭제.

## 코인 규칙 (모든 게임 공통)

- 게임 안에서 먹은 코인 1개 = 지갑 1코인
- 잘하는 1분 플레이 ≈ 코인 100~150개가 되도록 게임마다 코인 배치를 맞춤 (스카이훅 약 115/분, 헬리콥터 약 145/분)
- 보너스는 난이도에 비례
  - 스카이훅: 클리어 시 `20 + 스테이지번호×10 + 별×5`, 첫 클리어 +30
  - 헬리콥터: 100m마다 +5

## 새 게임 추가하는 법

1. `새게임/` 폴더를 만들고 `index.html`에서 `../common/profile.js`를 `game.js`보다 먼저 불러요.
2. `common/profile.js`의 `GAMES`와 `COIN_RULES`에 게임을 등록해요.
3. 게임 시작 시 `Hub.active().look`으로 캐릭터(`eunyu`/`eungyeol`)를 정하고,
   끝나면 `Hub.record('<게임id>', { dist, coins, ... })`를 불러 기록·코인을 저장해요.
4. 메인 화면 `index.html`의 게임 목록에 카드를 추가해요 (`hub/hub.js`의 `renderLobby`).

각 게임 폴더는 메인 화면 없이 단독으로 열어도 동작해요(기록은 그 게임 안에만 저장).
