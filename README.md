# 트윈 게임랜드

은유·은결 캐릭터로 여러 미니게임을 하는 모음집입니다. 캐릭터·코인·기록은 **이 기기(브라우저)에 저장**됩니다.

## 바로 플레이

**https://sangbiny-creater.github.io/twin-gameland/** — 아이폰 Safari에서 열고 공유 → '홈 화면에 추가' 하면 앱처럼 전체화면으로 실행돼요.

고친 뒤 `git push` 하면 1~2분 안에 위 주소에 반영돼요.

- 화면 확인 도구: `node tools/screen_check.mjs <폴더> [이름 필터]` (헤드리스 Chrome으로 폰·태블릿 화면 캡처 + 오류·404 + 놀이공원 편집 시험).

## 흐름

1. **캐릭터 선택(첫 화면)** — 처음엔 2명(은유·은결)까지 무료로 만들 수 있어요. 3번째부터는 코인으로 자리를 사요 (300 → 600 → 900 …, 최대 8명).
2. **게임 고르기** — 캐릭터를 고르면 게임 목록이 나와요. 아이템샵은 '오픈 예정'.
3. **Sky Hook Runner** — 징검다리 지도에서 스테이지를 골라요. 50스테이지(10개 월드 × 5판, 1-1 ~ 10-5), 앞 판을 깨야 다음 판이 열려요. 남은 하트 = 별(최대 3개).
4. **Twin Helicopter** — 끝없이 날아가며 최고 거리를 갱신해요.
5. **계단 오르기** (세로 전용) — 무한의 계단처럼 위로 가기 / 방향 전환으로 계단을 올라요. 시간이 줄어들고, 하트를 먹으면 이어하기 목숨이 생겨요. PC는 ↑ = 위로 가기, 스페이스 = 방향 전환.
6. **사천성** (`shisen/`, 폰은 세로) — 같은 그림 타일 2개를 2번까지 꺾이는 선으로 이어 없애요. 스카이훅처럼 징검다리 50판(하늘도시 → … → 황금성, 10개 월드 × 5판, 월드 5~10은 전용 그림 타일), 남은 시간으로 별 1~3개. 힌트·섞기·시간 추가 아이템, 콤보, 짝이 없으면 자동 섞기. PC는 H=힌트, S=섞기, T=시간 추가.
7. **다운힐 러너** (`downhill/`, 폰은 세로) — 후방 시점으로 눈 덮인 산길을 내려가며 좌우(5칸)로만 움직여 장애물을 피해요. 하트 3개, 300m마다 배경이 바뀌고(눈 덮인 산 → 겨울 숲 → 얼음 계곡 → 눈 마을 → 오로라 설원) 멀리 갈수록 빨라져요. 콤보·NICE(아슬아슬 회피) 보너스, 자석·보호막·부스터·무적 아이템. PC는 ← →.
8. **즐겨찾기** — 게임 카드 오른쪽 위 ☆를 누르면 즐겨찾기(캐릭터마다 따로). 즐겨찾기한 게임이 앞에 나오고 '★ 즐겨찾기'로 모아 볼 수 있어요.
9. **아이템 샵** (`shop/`) — 게임마다 따로 사는 **배경 스킨**(한 번 사면 계속, '적용하기'로 바꿈)과 **게임 부스트**(1회용, '사용중'으로 켜 둔 것만 게임 시작 때 1개씩 쓰임). 캐릭터마다 코인·아이템이 따로예요.
10. **기록** — 캐릭터별 코인, 게임별 최고 기록·도전 횟수, 최근 기록 30개. 이름 바꾸기 / 캐릭터 삭제.

## 코인 규칙 (모든 게임 공통)

- 게임 안에서 먹은 코인 1개 = 지갑 1코인
- 잘하는 1분 플레이 ≈ 코인 100~150개가 되도록 게임마다 코인 배치를 맞춤 (스카이훅 약 115/분, 헬리콥터 약 145/분, 계단 오르기 약 100~130/분)
- 보너스는 난이도에 비례
  - 스카이훅: 클리어 시 `20 + 스테이지번호×10 + 별×5`, 첫 클리어 +30
  - 헬리콥터: 100m마다 +5
  - 계단 오르기: 50계단마다 +5
  - 다운힐 러너: 100m마다 +5 (게임 안에서 10콤보마다·아슬아슬 회피마다 코인)
  - 사천성: 짝 1개 = 2코인(콤보면 +1), 클리어 보너스는 스카이훅과 같은 규칙

## 새 게임 추가하는 법

1. `새게임/` 폴더를 만들고 `index.html`에서 `../common/profile.js`를 `game.js`보다 먼저 불러요.
2. `common/profile.js`의 `GAMES`와 `COIN_RULES`에 게임을 등록해요.
3. 게임 시작 시 `Hub.active().look`으로 캐릭터(`eunyu`/`eungyeol`)를 정하고,
   끝나면 `Hub.record('<게임id>', { dist, coins, ... })`를 불러 기록·코인을 저장해요.
4. 메인 화면 게임 목록에 카드를 추가해요 (`hub/hub.js`의 `GAME_CARDS`에 한 줄).
   아이템샵에도 넣으려면 `common/profile.js`의 `BOOSTS`와 `shop/shop.js`의 `GAMES`에 추가하고,
   게임 시작 때 `Hub.equippedSkin('<게임id>')` / `Hub.takeBoosts('<게임id>')`로 스킨·부스트를 적용해요.
5. 고친 파일이 폰에서 바로 반영되도록 `python3 tools/bump_version.py`로 모든 `?v=` 캐시 버전을 한 번에 올려요.

각 게임 폴더는 메인 화면 없이 단독으로 열어도 동작해요(기록은 그 게임 안에만 저장).
