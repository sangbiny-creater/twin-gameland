## 흐름

1. **캐릭터 선택(첫 화면)** — 처음엔 2명(은유·은결)까지 무료로 만들 수 있어요. 3번째부터는 코인으로 자리를 사요 (300 → 600 → 900 …, 최대 8명).
2. **게임 고르기** — 캐릭터를 고르면 게임 목록이 나와요. 아이템샵은 '오픈 예정'.
3. **Sky Hook Runner** — 징검다리 지도에서 스테이지를 골라요. 12스테이지(1-1 ~ 4-3), 앞 판을 깨야 다음 판이 열려요. 남은 하트 = 별(최대 3개).
4. **Twin Helicopter** — 끝없이 날아가며 최고 거리를 갱신해요.
5. **계단 오르기** (세로 전용) — 무한의 계단처럼 위로 가기 / 방향 전환으로 계단을 올라요. 시간이 줄어들고, 하트를 먹으면 이어하기 목숨이 생겨요. PC는 ↑ = 위로 가기, 스페이스 = 방향 전환.
6. **즐겨찾기** — 게임 카드 오른쪽 위 ☆를 누르면 즐겨찾기(캐릭터마다 따로). 즐겨찾기한 게임이 앞에 나오고 '★ 즐겨찾기'로 모아 볼 수 있어요.
7. **아이템 샵** (`shop/`) — 게임마다 따로 사는 **배경 스킨**(한 번 사면 계속, '적용하기'로 바꿈)과 **게임 부스트**(1회용, '사용중'으로 켜 둔 것만 게임 시작 때 1개씩 쓰임). 캐릭터마다 코인·아이템이 따로예요.
8. **기록** — 캐릭터별 코인, 게임별 최고 기록·도전 횟수, 최근 기록 30개. 이름 바꾸기 / 캐릭터 삭제.

## 코인 규칙 (모든 게임 공통)

- 게임 안에서 먹은 코인 1개 = 지갑 1코인
- 잘하는 1분 플레이 ≈ 코인 100~150개가 되도록 게임마다 코인 배치를 맞춤 (스카이훅 약 115/분, 헬리콥터 약 145/분, 계단 오르기 약 100~130/분)
- 보너스는 난이도에 비례
  - 스카이훅: 클리어 시 `20 + 스테이지번호×10 + 별×5`, 첫 클리어 +30
  - 헬리콥터: 100m마다 +5
  - 계단 오르기: 50계단마다 +5

## 새 게임 추가하는 법

1. `새게임/` 폴더를 만들고 `index.html`에서 `../common/profile.js`를 `game.js`보다 먼저 불러요.
2. `common/profile.js`의 `GAMES`와 `COIN_RULES`에 게임을 등록해요.
3. 게임 시작 시 `Hub.active().look`으로 캐릭터(`eunyu`/`eungyeol`)를 정하고,
   끝나면 `Hub.record('<게임id>', { dist, coins, ... })`를 불러 기록·코인을 저장해요.
4. 메인 화면 게임 목록에 카드를 추가해요 (`hub/hub.js`의 `GAME_CARDS`에 한 줄).
   아이템샵에도 넣으려면 `common/profile.js`의 `BOOSTS`와 `shop/shop.js`의 `GAMES`에 추가하고,
   게임 시작 때 `Hub.equippedSkin('<게임id>')` / `Hub.takeBoosts('<게임id>')`로 스킨·부스트를 적용해요.
5. 고친 파일이 바로 반영되도록 각 `index.html`의 `?v=` 버전 번호를 올려요.

각 게임 폴더는 메인 화면 없이 단독으로 열어도 동작해요(기록은 그 게임 안에만 저장).
