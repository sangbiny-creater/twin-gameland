# 다운힐 러너 앱 (`downhill-app/`)

다운힐 러너 한 게임만 하는 **단독 앱**이에요. 나중에 앱스토어·플레이스토어에 올릴 앱의 바탕이에요.
트윈 게임랜드 사이트(`index.html`, `hub/`, 다른 게임)와는 따로 동작하고, 사이트 파일을 건드리지 않아요.

- 주소: **https://downhill.brown-crab.com/** (백오피스 https://downhill.brown-crab.com/admin/)
- 올리기: 여기서 고치고 커밋한 뒤 `bash tools/publish_downhill.sh` → GitHub 저장소 `sangbiny-creater/downhill`(GitHub Pages + 도메인 downhill.brown-crab.com)로 복사해서 올라가요.
  예전 주소(sangbiny-creater.github.io/twin-gameland/downhill-app/)로 들어오면 새 주소로 넘겨요.
- 로컬: 저장소 맨 위 폴더에서 `python3 -m http.server 8080` → http://localhost:8080/downhill-app/

## 화면 흐름

1. **인트로** — 세로 인트로 그림만 (START 버튼 없음). 화면을 누르거나 2.5초 뒤 다음으로.
   - 완전 처음 접속이면 **언어 고르기**(한국어 / English). 영어판 글자 표는 `lib/i18n_data.js` (앱 글자를 바꾸면 여기에도 영어를 넣기)
2. **로그인** (처음 한 번) — 구글 로그인 · 이메일 로그인(가입하기·비밀번호 재설정 메일, Firebase) · 게스트로 시작.
3. **약관 동의** (처음 한 번) — ☐ [필수] 개인정보 수집·이용 동의(보기) · ☐ [필수] 이용약관 동의(보기) · 개인정보 처리방침(보기만). 위 두 개를 체크해야 다음으로.
4. **이름 만들기** (처음 한 번) — 계정 하나에 이름 하나 (영어 15자 · 한글 7자까지 — 한글 한 글자를 영어 두 글자 폭으로 셈). 같은 이름은 하나만 (서버 `names` 모음 — 트윈 게임랜드 사이트 이름과 같은 목록이라 사이트 이름과도 겹치지 않음).
   인터넷이 안 되면 일단 쓰고 다음 접속 때 등록, 그새 다른 사람이 쓰면 새 이름을 정하게 함.
5. **캐릭터 고르기** — 트윈 게임랜드 첫 화면과 같은 배치·카드 비율(얼굴 크기·자르는 자리), 아래 이름·코인 칸 없음, 오른쪽 위 언어 버튼. 겨울옷 그림. 창 색이 여자 분홍 · 남자 파랑.
6. **시작 창** — 로고 · 이름/BEST · "시작하기" · "N판부터 시작"(2판 이상일 때만) · "랭킹보기". 오른쪽 위 설정(계정·소리·언어·캐릭터 바꾸기·약관). 결과·일시정지의 "다시하기"도 이 창으로.
   - **랭킹** — 트윈 게임랜드 주간 랭킹 화면 모양, 주간/전체 + 거리/코인 탭(아이템샵 탭 그림). 내 줄을 누르면 자랑하기.
7. **게임** — 화면 맨 위에 광고 자리(지금은 빈 자리), 게임은 그 아래.
8. **결과** — 제목 "게임 끝" / 기록을 깨면 "최고 기록 달성!" + NEW BEST!(트윈 게임랜드와 같음, 캐릭터 그림 없음) · "광고 보고 이어하기"(한 판에 한 번) · "다시하기" · "자랑하기" · 오른쪽 위 X.
9. **자랑하기** — 휴대폰 공유 창(카카오톡·문자 등)으로 기록 + 앱 링크(`?from=기록&by=이름`)를 보내요. 공유 창이 없으면 "문자로 보내기"·"링크 복사".
   친구가 그 링크로 들어오면 시작 상자에 "OOO님 기록 OOOm를 넘어 보세요!", 결과 화면에 넘었는지 보여 줘요.

창(팝업)은 모두 트윈 게임랜드 팝업 그림(`lib/ui/popup/` = `common/ui/popup/v4` 복사본: 창 틀·리본·버튼·X)을 그대로 써요.

가로 화면은 지원하지 않아요 (폰·태블릿을 가로로 돌리면 "세로로 돌려 주세요"). PC에서는 가운데 세로 칸으로 보여요.

## 파일

| 파일 | 내용 |
|---|---|
| `index.html` · `app.css` · `app.js` | 앱 화면(인트로·로그인·고르기·시작 상자·결과·자랑하기·광고 자리)과 흐름 |
| `game.js` · `style.css` | `downhill/` 게임을 **복사**해서 앱에 맞게 고친 것 (게임 규칙은 같음). 원본 게임을 고치면 여기에도 옮겨야 해요 |
| `assets/` | 게임 그림(`downhill/assets` 복사) + `assets/app/`(인트로·임시 배경·임시 아이콘·공유 미리보기) |
| `lib/` | 공통 파일 복사본: 겨울옷 캐릭터 그림(`chars/`), 글꼴(`fonts/`), 하트·왕관·팝업 그림(`ui/`), `charv2.js`(줄인 것), `firebase_config.js` |
| `manifest.json` | 앱 이름·아이콘, 세로 고정(`orientation: portrait`) |

앱으로 묶을 때 폴더 하나만 있으면 되도록 `../common/` 같은 바깥 파일은 쓰지 않아요.

## 저장

- 이 기기 저장: `localStorage` 의 `downhill_app_v1` (로그인 상태·약관 동의·이름·캐릭터·BEST·코인·마지막 판).
- 사이트 저장(`twin_gameland_v1`)·사이트 다운힐 저장(`downhill_v1`)은 읽지도 쓰지도 않아요.
- 서버(사이트와 같은 Firebase 프로젝트 `twin-gameland`, 규칙은 `server/firestore.rules` 그대로):
  - `users/{uid}.dh` = { name, char, best, plays, lastZone, agreedAt, agreeVer, createdAt, lastAt } — 다른 기기에서 로그인하면 이걸로 이어 해요
  - `names/{이름}` = { uid, name, app: 'downhill' } — 같은 이름은 하나만
  - `records` (game `downhill-app`) — 한 판 기록 · `config/downhill` — 공지·점검 (백오피스에서 씀)
- 게스트도 서버에는 익명 계정으로 들어가요 (이름 중복 확인 때문). 게스트가 로그아웃하면 이름을 놓아줘요.
