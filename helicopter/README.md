# Twin Helicopter (은유와 은결의 하늘 모험!)

예전 플래시 "헬리콥터 게임"처럼 **누르고 있으면 올라가고, 떼면 내려가는** 원버튼 횡스크롤 게임입니다.
기획서 이미지와 `asset.PNG`(투명 배경 에셋)를 잘라 만든 그림을 그대로 사용합니다.

## 실행

```bash
cd helicopter
python3 -m http.server 8081 --bind 0.0.0.0
```

PC: http://localhost:8081 · 아이폰(같은 Wi‑Fi): http://<맥 IP>:8081

## 조작

| 동작 | PC | 스마트폰 |
| --- | --- | --- |
| 상승 | Space / ↑ / 마우스 누르고 있기 | 화면 꾹 누르기 |
| 하강 | 손 떼기 | 손 떼기 |
| 일시정지 / 다시하기 | Esc·P / R | 왼쪽 위 버튼 |

## 게임 규칙

- 위아래 파이프 사이로 계속 날아가요. 점점 빨라지고 틈이 좁아져요.
- 하트 3개로 시작(최대 4개). 파이프·장애물·땅에 부딪히면 하트 -1, 0이 되면 추락.
- 500m마다 테마가 바뀌어요: 하늘도시 → 숲속마을 → 놀이공원 → 겨울왕국 → 석양의 항구 → (반복)
- 아이템: 코인, 파란 보석(+5), 핑크 보석(+10), 하트(+1), 자석(7초), 쉴드(1회 보호), 번개(3초 스피드 + 무적)
- 최고 기록(BEST)과 총 코인은 기기에 저장돼요.

## 파일

- `index.html`, `style.css`, `game.js` — 게임 본체 (외부 라이브러리 없음)
- `assets/sprites.webp` + `sprites.json` — asset.PNG에서 잘라낸 스프라이트 아틀라스
- `assets/bg_0~4.jpg` — 테마별 배경 띠, `assets/keyart.jpg` — 홈 화면 타이틀 그림
- 조작감·난이도 값은 `game.js` 맨 위 `CFG`, 테마는 `THEMES`에 있어요.
